# TC-LOGIN-001 登录状态冒烟检查

来源：
- POC 示例用例，等待替换为真实 PRD 与原型来源。

前置条件：
- 已配置 `TEST_BASE_URL`。
- 已配置可用测试账号，或已通过 Chrome Bridge Mode 复用登录态。
- 不执行任何生产写入动作。

步骤：
1. 打开测试环境首页或登录页。
2. 断言页面正常打开，没有浏览器错误页、服务端 500 错误或明显白屏。
3. 如果未登录，则使用测试账号完成登录。
4. 等待首页或业务主页面加载完成。
5. 断言页面显示用户头像、用户名或主导航。

失败归因参考：
- 页面打不开：环境或网络问题。
- 无法登录：账号、验证码、权限或产品缺陷。
- 登录后无主导航：权限问题、需求不明确或真实缺陷。
