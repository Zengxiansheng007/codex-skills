# Repository guidance

## Agent skills

### Issue tracker

Specs and work items use GitHub Issues in `Zengxiansheng007/codex-skills`. Read `docs/agents/issue-tracker.md` before reading or publishing work items.

### Triage labels

Use the five canonical roles recorded in `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context rules in `docs/agents/domain.md`. For JMeter work, begin with `jmeter/README.md` and its current specification and glossary links.

Publication, implementation, runtime qualification and installation are separate outcomes. Follow each Issue's scope and acceptance conditions; do not infer execution authorization from a label or copied package.
