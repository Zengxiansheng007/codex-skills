# Triage labels

Default vocabulary confirmed by the repository owner on 2026-10-14.

| Canonical role | Repository label | Meaning |
|---|---|---|
| needs-triage | needs-triage | Maintainer evaluation required |
| needs-info | needs-info | Waiting for necessary information |
| ready-for-agent | ready-for-agent | Specified work ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Reuse existing labels and preserve unrelated labels. A ready label identifies a workflow role; product acceptance, installation and authority to execute a specific live task still require the evidence and scope stated in the Issue.
