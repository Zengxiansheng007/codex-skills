# figma-rest-sync Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\figma-rest-sync`.
2. Keep scripts, cache schema, references, and validation assets together.
3. Configure the required Figma Personal Access Token on the target machine when first used. Do not store tokens inside the skill folder.
4. Restart Codex or open a new task.

## Use
Use `figma-rest-sync` when Codex needs to read, validate, cache, search, or export Figma design data through the Figma REST API.

```text
使用 figma-rest-sync 读取这个 Figma 文件并导出可检索的本地设计索引。
```
