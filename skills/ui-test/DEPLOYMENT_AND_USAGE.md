# ui-test Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\ui-test`.
2. Preserve references, execution guidance, templates, and scripts.
3. Ensure the target machine has required browser/test tooling before running UI automation.
4. Restart Codex or open a new task.

## Use
Use `ui-test` to plan, execute, repair, and stabilize Agent-driven Web UI tests using visual exploration, Playwright verification, and evidence reporting.

```text
使用 ui-test 根据 PRD 和页面截图设计并执行 UI 测试，输出证据链和失败归因。
```
