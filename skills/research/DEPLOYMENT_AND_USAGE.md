# research Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\research`.
2. Preserve references, scripts, templates, and evidence-quality rules.
3. Ensure the target Codex environment has network access when public-source research is required.
4. Restart Codex or open a new task.

## Use
Use `research` to collect high-trust references, assess evidence quality, run recursive critique loops, and produce cited reports.

```text
使用 research 检索参考资料与参考 Skill，评审优缺点，并补强到没有 P0/P1 缺陷。
```
