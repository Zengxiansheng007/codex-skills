# 文献入库 skill 测试计划（v1.0）

## 1. 测试目标

验证 `rag-structure-fidelity` 是否能在入库阶段稳定守住结构保真、阻断边界和候选边界。

## 2. 测试范围

覆盖内容：
- `md` 正文解析
- `doc/docx` 结构抽取
- `pdf` 文本层解析
- 扫描件 / 图片型 PDF 阻断
- `.lakebook` 目录对照
- 表格、列表、图片引用处理
- 结构化产物与证据 JSON
- 关键规则区块阻断
- 不自动生成 RC
- 不直接组下游包

不覆盖内容：
- 真实生产数据
- 自动扫描全盘目录
- 下游 `ui-test` / `auto-testcase-generator` / Solution D 实际执行
- 正式 RC 审批

## 3. 入口 / 退出标准

| 类型 | 标准 |
|---|---|
| 入口 | 已确认 `md` 为正文主输入；已确认 `.lakebook` 仅作目录对照；已确认允许的格式范围 |
| 暂停 | 发现敏感信息、扫描件、来源不明文件、目录与正文严重冲突 |
| 退出 | 结构校验通过，P0/P1 归零，阻断规则生效，候选层不越权 |

## 4. 测试矩阵

| ID | 场景 | 期望结果 |
|---|---|---|
| TC-01 | md 正文导入 | 生成结构化正文、structure map、evidence JSON |
| TC-02 | lakebook 目录与正文不一致 | 记录候选映射，但不自动放行 |
| TC-03 | doc/docx 含表格 | 表格按整表保留 |
| TC-04 | doc/docx 含列表 | 列表按整块保留 |
| TC-05 | 正文含图片引用 | 保留引用和位置，不内嵌二进制 |
| TC-06 | 扫描件 PDF | 硬阻断 |
| TC-07 | 图片型 PDF | 硬阻断 |
| TC-08 | 关键规则区块不可复原 | 区块级阻断 |
| TC-09 | 文件整体失真 | 文件级总状态阻断 |
| TC-10 | 候选证据输出 | 只生成 candidate，不生成 RC |
| TC-11 | 试图直接组下游包 | 阻断，交给 `rag-downstream-handoff` |
| TC-12 | 敏感字段出现 | 拒绝入库并记录原因 |

## 5. 测试数据

建议准备 4 类 fixture：
- 正向 md 正文 fixture
- 正向 docx / 文本层 PDF fixture
- 负向扫描 PDF fixture
- 负向目录错位 / 规则失真 fixture

所有 fixture 只允许使用脱敏材料或合成材料。

## 6. 判定规则

- P0：敏感信息误入库、扫描件放行、跨空间混入、自动 RC、自动下游放行
- P1：结构失真、表格/列表拆坏、关键规则区块未阻断、候选映射越权
- P2：报告可读性、字段命名、提示文案、覆盖率细节

## 7. 验收输出

- Admission / Reject report
- structure map JSON
- evidence JSON
- validation report
- fixture 执行记录

## 8. 回归触发

以下变化必须回归：
- 支持格式变化
- 阻断规则变化
- 结构块定义变化
- 目录映射规则变化
- 输出 JSON 字段变化
