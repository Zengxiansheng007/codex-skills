2. 非目标与禁止项

  • 不自动扫描磁盘，不读取用户清单外文件。
  • 不保存账号、密码、API Key、访问令牌、浏览器 Cookie、未脱敏生产客户数据、未脱敏日志或截图。
  • 不把 PRD、历史记录或检索命中直接登记为 RC。
  • 不把 active 当正式依据；正式 RC 必须为 confirmed_active 或用户明确确认。
  • 不从 rag-system MVP 直接执行 ui-test、生成正式测试用例、写入下游系统或触达生产环境。
