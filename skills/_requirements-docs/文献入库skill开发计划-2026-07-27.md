# 文献入库 skill 开发计划（v1.0）

## 1. 目标

把“结构可复原的文献”稳定入库到本地 RAG 知识库，优先保证结构保真，再考虑覆盖率。

核心目标：
- 以 `md` 正文作为唯一正文输入
- `lakebook` / 语雀仅作为目录对照和备用来源
- 只生成候选结构与候选证据，不自动进入 RC
- 扫描件、图片型 PDF、关键规则区块不可复原时硬阻断
- 结果只交给 `rag-intake` 之后的后续治理链路，不直接组下游包

## 2. 已冻结决策

| 项 | 决策 |
|---|---|
| 正文输入 | `md` 作为唯一正文输入 |
| 目录来源 | 语雀 / `.lakebook` 只做目录分层和备用参考 |
| 支持格式 | `doc` / `docx` / `pdf` / `md` |
| 图片处理 | 正文中保留引用和位置，不内嵌二进制 |
| 表格处理 | 按整表判定 |
| 列表处理 | 按整块判定，子项只做定位 |
| 阻断策略 | 关键规则区块阻断 + 文件级总状态阻断 |
| RC 规则 | 不自动生成 RC |
| 下游 | 不直接输出下游包，统一交给 `rag-downstream-handoff` |

## 3. 交付物

1. `rag-structure-fidelity/SKILL.md`
2. `rag-structure-fidelity/references/*.md`
3. 结构化产物契约说明
4. 结构保真校验清单
5. 负向/正向 fixture 清单

## 4. 模块拆分

| 模块 | 职责 | 产物 |
|---|---|---|
| 输入归类 | 识别 `doc/docx/pdf/md` 与 `.lakebook` 目录材料 | 输入判定记录 |
| 目录对照 | 比较正文标题与语雀层级 | alias / outline 候选映射 |
| 结构抽取 | 提取段落、表格、列表、图片引用、标题层级 | structure map JSON |
| 复原性判定 | 对语义块做可复原性判断 | candidate verdict |
| 阻断判定 | 对关键区块、扫描件、图片型 PDF 做阻断 | reject / blocked report |
| 证据生成 | 仅生成候选证据与来源引用 | evidence JSON |
| 验证输出 | 输出可校验报告 | validation report |

## 5. 分阶段计划

### P0 冻结规则
- 固化输入输出边界
- 固化阻断条件
- 固化候选/正式边界

### P1 Skill 骨架
- 生成 `SKILL.md`
- 补齐 `references/`
- 明确触发词、输入、输出、硬规则

### P2 结构契约
- 定义 `structure map JSON`
- 定义 `evidence JSON`
- 定义 admission / reject / validation 报告字段

### P3 fixture 与校验
- 制作 md、docx、文本层 PDF、扫描 PDF、表格、列表、图片占位 fixture
- 覆盖关键规则区块阻断场景

### P4 复核与封板
- 用 fixture 跑全量回归
- 检查是否存在自动 RC、自动下游放行、正文失真
- 形成首版可交付 skill 草案

## 6. 验收标准

- md 正文可稳定解析
- `.lakebook` 只用于目录对照，不进入正文抽取
- 扫描件 / 图片型 PDF 硬阻断
- 表格、列表、图片引用的保真规则可被解释
- 关键规则区块可单独阻断
- 不自动生成 RC
- 不自动组下游包
- 产物可通过基础结构校验

## 7. 风险

- 语雀目录与正文层级不一致
- 图片内规则无法自动转成正式证据
- doc / pdf 复杂布局导致局部不可复原
- 过度自动映射可能污染候选层
