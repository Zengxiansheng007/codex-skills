Key Findings

缺口补充资料/Skill补强后建议剩余级别
F-001：测试计划未单列 rag-system Skill 测试矩阵。Promptfoo Test Agent Skills、Promptfoo Coding Agents、本地 create-agent-skill。新增触发、误触发、skill-used、子 Skill 路由、read-only sandbox、approval 观察、forward-test 和成本/延迟测试。MVP 不依赖 Promptfoo 运行，只吸收测试设计。0 个 P0/P1；待实施。

F-003：子 Skill 只有名称和职责，缺少最小文件结构与验证命令。Open Agent Skills Specification、GitHub Copilot Skills、本地 create-agent-skill rubric。每个 MVP 子 Skill 只保留 SKILL.md、必要 references/、必要 scripts/、fixtures；禁止教程化膨胀；创建前做结构校验、敏感扫描、forward-test。0 个 P0/P1；待授权创建。
F-004：SQLite FTS5 阈值定性。SQLite FTS5、Promptfoo RAG 评测、DeepEval RAG 指标。保留后置；首批语料后登记可调阈值：黄金查询失败率、人工查找耗时、语料条目量、重建一致性、中文查询失败类型。P2，非 MVP 阻塞。
F-005：计划变更后缺少 Skill 级回归规则。OWASP AI Agent、MCP Tools、Promptfoo Coding Agents、OpenAI Agents SDK guardrails/tracing。任何触发描述、状态机、packet schema、下游字段、拒绝规则变更后，回归 Skill 触发/误触发、路由、审批拒绝、packet schema、黄金查询和安全拒绝集。P2，建议纳入新版测试计划。

Evidence Table

S01Open Agent Skills Specification明确 Skill 至少包含 SKILL.md，可选 scripts/、references/、assets/，并强调渐进加载。允许可选 frontmatter 字段，但本地 Codex 规则更严格。作为通用结构参考；本地实现以 create-agent-skill 为准。
S02GitHub Copilot Skills说明 Skill 目录、SKILL.md、脚本资源和安装预览；警告第三方 Skill 可能含隐藏指令或恶意脚本。面向 Copilot，不等同 Codex runtime。吸收安装前审查、版本 pin、脚本谨慎预批准。
S03Promptfoo Test Agent Skills直接覆盖“Skill 是否被使用、是否误用附近 Skill、版本对比、结构化输出、skill-used、trace 证据”。运行 Promptfoo 需外部依赖；不适合 MVP P0 必跑。作为 forward-test 设计参考；真实执行后置 P2/CI。
S04Promptfoo Coding Agents强调 Agent 评测是系统评测，需要观察工具轨迹、审批、sandbox、成本、延迟和非确定性。部分 provider/模型版本会变化，需运行时复核。支撑 Skill 级测试矩阵和 read-only 评测环境。
S05JSON Schema Validation可用 type、required、enum、数值/数组/对象约束验证 packet 结构。只能验证结构，不能证明证据真实性或 RC 合法性。作为结构门禁；语义门禁另用状态机和证据回链。
S06OpenAPI Specification 3.2.0强调接口描述可降低猜测，支持 humans/computers 理解能力边界。偏 HTTP API；本项目 packet 不一定是 HTTP 服务。吸收 schema、examples、readOnly/writeOnly、版本描述思想。
S07Pact Docs说明 contract testing 可用具体 request/response 样例验证消费者实际使用的交互。Pact 本身是代码型集成测试工具，MVP 不应引入依赖。吸收“契约即示例”思想，为下游 packet 建正反例 fixture。
S08Semantic Versioning 2.0.0公开 API 需清晰精确；破坏性变化、兼容新增、修复应对应版本变化。SemVer 面向软件包；知识库 packet 可采用但不必机械照搬。用于 schema_version 和下游兼容规则。
S09MCP Tools Spec工具有 input/output schema；建议人可拒绝工具调用；结构化结果可由客户端验证。当前 rag-system 是 Skill，不是 MCP server。作为未来工具化和审批/输出 schema 参考。
S10OWASP AI Agent Security支持最小权限、人工审批、外部输入校验、记忆隔离、结构化输出和发布门禁。不是本地 RAG 目录规范。转成拒绝集、审批门禁、安全回归和日志字段。
S11OWASP LLM Top 10覆盖提示注入、输出处理、供应链、敏感泄露等风险。风险清单偏通用，需映射到本地测试夹具。支撑文档提示注入测试和第三方 Skill 不直接执行。
S12SQLite FTS5支持 BM25、rank、integrity-check、rebuild、secure-delete 等本地全文检索能力。中文分词、外部内容一致性和删除残留需要本地实测。只作为 08_cache 后置 POC，不作事实源。
S13Promptfoo RAG Evaluation建议分开评估检索和生成，支持 context recall/relevance/faithfulness 方向。部分指标使用模型裁判，不能做 P0/P1 唯一依据。P2 评测参考；MVP 主验收仍用确定性黄金查询。
S14DeepEval Agent Evaluation支持 trace、TaskCompletionMetric、子 Agent/span 级评测。引入框架和外部模型裁判成本。后续 rag-eval POC，可辅助分析子 Skill 表现。
S15DeepEval Faithfulness明确 faithfulness 评估输出是否被 retrieval context 支撑。LLM-as-a-judge，不适合作为强门禁唯一来源。用于 P2 语义评测，不替代证据引用和状态机。
S16OpenAI Agents SDK Guardrails / Tracingguardrails、tool guardrails、handoffs、tracing 可支持 Agent 工作流观测。这是 SDK 运行时资料，当前 Codex Skill 不直接依赖。吸收“阻断结果可观测、trace 不应含敏感数据”的设计思想。
L01本地 create-agent-skill最贴近 Codex Skill 创建规则：短 SKILL.md、渐进加载、validator、forward-test。不负责 RAG 业务规则。作为 rag-system 与子 Skill 文件结构主规范。
L02本地 auto-testcase-generator提供下游用例生成的溯源、增量维护、状态门禁和 JSON trace 要求。不应被 rag-system 直接执行。定义 Test Asset Manifest 消费者契约。

Iterative Gap Closure

轮次发现的问题补充资料/Skill 后的评审结论
R1Skill 测试矩阵缺失，可能只测数据层不测 Agent 使用入口。Promptfoo Test Agent Skills 直接支撑 skill-used、误触发、版本对比；本地 create-agent-skill 要求 forward-test。P1 关闭：新增 TC-RAG-SKILL 系列作为计划修订项。
R2Packet 只有字段名，跨下游解释不稳定。JSON Schema 提供结构约束；Pact 提供“具体交互样例”思路；SemVer 支撑兼容规则。P1 关闭：要求 schema + fixture + version 三件套。
R3子 Skill 结构不具体，可能膨胀或缺少校验。Open Agent Skills、GitHub Skills、本地 rubric 一致支持最小结构、脚本审查、安装前检查。P1 关闭：每个子 Skill 需文件清单、校验命令、拒绝条件、forward-test。
R4Agent 安全测试容易停在“提示注入”单点。OWASP AI Agent 与 MCP Tools 扩展到最小权限、审批绑定、工具 schema、输出校验、发布门禁。P1 关闭：安全测试需覆盖拒绝、审批、工具边界、结构化输出和敏感数据不进入 trace/report。
R5FTS5 阈值仍偏定性。SQLite FTS5 官方能力足够支撑后置 POC；Promptfoo/DeepEval 可补评测思路。保留 P2：需首批语料后定量化，不阻塞 MVP。
R6LLM 评测工具可能带来“模型裁判即真值”的新风险。Promptfoo 和 DeepEval 都提供有用 RAG/Agent 评测，但 faithfulness 等指标不应替代确定性 schema、RC 状态和引用回链。P1 关闭：LLM judge 仅 P2 辅助，P0/P1 主验收用确定性证据。

Conflicts And Uncertainty

冲突/不确定性处理

SQLite FTS5 支持强本地检索，但中文分词和外部内容一致性需要真实语料。保留后置 POC；MVP 文件索引继续成立。
