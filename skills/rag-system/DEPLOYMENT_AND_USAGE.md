# rag-system Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\rag-system`.
2. Install the related `rag-*` child skills when full local RAG routing is needed.
3. Confirm the target machine has the expected RAG root, normally `D:\RAG`, or adapt prompts/configuration to the new path.
4. Restart Codex or open a new task.

## Use
Use `rag-system` as the top-level router for local knowledge base intake, query, governance, schema validation, change impact, structure fidelity, and downstream handoff.

```text
使用 rag-system 检索 D:\RAG，并根据证据回答这个业务规则问题。
```
