# task-understanding-router Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\task-understanding-router`.
2. Keep routing rules and references together.
3. Restart Codex or open a new task.

## Use
Use `task-understanding-router` to frame a new task, classify intent, and route to direct execution, clarification, approval gate, or `grill-system`.

```text
使用 task-understanding-router 先理解我的需求并判断应该直接执行还是进入 grill-system。
```
