# create-skill Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\create-skill`.
2. Preserve bundled references, scripts, templates, and validation assets.
3. Restart Codex or open a new task.

## Use
Use `create-skill` when designing, reviewing, or packaging reusable Codex skills with PRD, development, and test planning support.

```text
使用 create-skill 生成这个新 Skill 的需求、开发计划、测试计划和 SKILL.md。
```
