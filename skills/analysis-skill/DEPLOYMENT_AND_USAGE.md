# analysis-skill Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\analysis-skill`.
2. Keep bundled `references/`, `scripts/`, and fixtures together.
3. Restart Codex or open a new task so the skill registry reloads.

## Use
Use `analysis-skill` to review a local, ZIP, or staged GitHub Agent Skill before adoption, installation, migration, or rewrite.

```text
使用 analysis-skill 评审这个 Skill 的安全性、兼容性和可迁移性。
```
