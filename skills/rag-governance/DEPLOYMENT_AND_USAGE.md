# rag-governance Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\rag-governance`.
2. Keep governance references, schemas, and report templates with the skill.
3. Confirm the target RAG workspace path, normally `D:\RAG`.
4. Restart Codex or open a new task.

## Use
Use `rag-governance` to decide whether candidate knowledge can become RC and to manage active, uncertain, deprecated, or superseded states.

```text
使用 rag-governance 审核这些候选证据，只有我确认后才能进入 RC。
```
