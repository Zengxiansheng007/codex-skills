# session-handoff Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\session-handoff`.
2. Keep handoff templates, validators, and evidence-marker rules together.
3. Restart Codex or open a new task.

## Use
Use `session-handoff` to create redacted, evidence-marked handoff documents for another Codex, WorkBuddy, Claude, or generic agent.

```text
使用 session-handoff 为当前任务生成中文交接文档，包含状态、证据、下一步和授权边界。
```
