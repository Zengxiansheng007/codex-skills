# PH-4 Installation And Operations Contract

## Compatibility And Rollback

Promotion requires compatible evidence for the Skill body, references, schemas, scripts, fixtures, reports, change records and handoff interface. Source hash, target baseline hash, backup plan and rollback plan are mandatory. Workspace validation is candidate evidence only and never installation authority.

## Exact Installation Approval

A user-level installation requires an active, time-bounded user approval bound to the exact source hash, target path, target baseline hash, coverage, backup manifest and rollback plan. Missing, expired or changed fields fail closed as `blocked-user-decision`. Dry-run readiness does not perform installation.

## Operations Governance

The operations projection must preserve stable machine state plus Chinese display status, hash-linked event and decision references, resource and failure budgets, evidence retention, maintenance references and audit reconstruction. An Agent claim or successful copy cannot mark installation or Development System completed.
