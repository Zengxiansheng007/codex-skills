# skill-packager Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\skill-packager`.
2. Keep packaging policy, validation rules, scripts, and templates with the skill.
3. Restart Codex or open a new task.

## Use
Use `skill-packager` to package, audit, adapt, validate, migrate, or deploy Codex Agent Skills across machines or agents.

```text
使用 skill-packager 打包全部本地 Skill，并生成迁移审计和每个 Skill 的部署使用说明。
```
