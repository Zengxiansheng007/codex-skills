# create-agent-skill Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\create-agent-skill`.
2. Keep `references/`, `agents/`, and validation scripts in the same folder.
3. Restart Codex or open a new task.

## Use
Use `create-agent-skill` to create, harden, validate, or document a Codex Agent Skill from a workflow, SOP, or repeated task.

```text
使用 create-agent-skill 帮我把这个流程设计成一个可部署的 Codex Skill。
```
