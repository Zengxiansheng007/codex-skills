# Review Rubric

Assess:

- `business_result`: did the intended business state happen?
- `execution_quality`: did the agent execute the intended steps?
- `assertion_strength`: do assertions prove the result?
- `evidence_completeness`: can a human and Codex inspect the result?
- `stability`: can the same chain rerun without rediscovery?
- `repairability`: are fixes tied to root causes?
- `promotion_readiness`: is the strategy safe to reuse?
