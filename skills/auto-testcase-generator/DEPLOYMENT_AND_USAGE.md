# auto-testcase-generator Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\auto-testcase-generator`.
2. Keep templates, references, scripts, and schemas together.
3. Restart Codex or open a new task so the skill is discovered.

## Use
Use `auto-testcase-generator` to generate and maintain traceable manual test cases from PRDs, screenshots, APIs, code evidence, or RAG evidence packets.

```text
使用 auto-testcase-generator 根据这些 PRD 和证据生成测试用例，并输出可追溯报告。
```
