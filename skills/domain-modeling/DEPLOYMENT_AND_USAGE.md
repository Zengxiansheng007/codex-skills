# domain-modeling Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\domain-modeling`.
2. Keep any bundled references and examples with the skill.
3. Restart Codex or open a new task.

## Use
Use `domain-modeling` to build a project vocabulary, glossary, or domain model.

```text
使用 domain-modeling 帮我整理这个项目的领域模型、术语表和关键决策。
```
