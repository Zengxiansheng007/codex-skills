# rag-intake Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\rag-intake`.
2. Keep precheck rules, references, scripts, and report templates together.
3. Confirm the target machine has the intended RAG root, normally `D:\RAG`.
4. Restart Codex or open a new task.

## Use
Use `rag-intake` when admitting user-provided files into the local knowledge base, checking allowed paths, sensitive data, metadata, and admission status.

```text
使用 rag-intake 对这批用户提供的文件做入库预检，并生成接收/阻断报告。
```
