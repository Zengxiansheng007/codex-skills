# Locator Policy

Recommended priority:

1. role plus accessible name;
2. label;
3. placeholder plus scoped container;
4. stable test id or stable attribute;
5. scoped text filter;
6. short CSS or XPath only when semantic locators are unavailable;
7. coordinate click as last-resort fallback and always mark high risk.

Do not suggest frontend test-contract additions unless explicitly allowed by the user.
