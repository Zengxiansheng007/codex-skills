# grill-system Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\grill-system`.
2. Keep routing rules, references, scripts, and report templates with the folder.
3. Restart Codex or open a new task.

## Use
Use `grill-system` to stress-test requirements, plans, risks, implementation choices, test strategies, and handoffs through structured questioning.

```text
使用 grill-system 评审这份需求和开发测试计划，找出需要我确认的问题。
```
