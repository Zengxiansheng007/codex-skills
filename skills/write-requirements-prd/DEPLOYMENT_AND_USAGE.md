# write-requirements-prd Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\write-requirements-prd`.
2. Keep templates, references, and validation rules with the skill.
3. Restart Codex or open a new task.

## Use
Use `write-requirements-prd` to draft, review, or convert notes, rules, state machines, UI automation needs, development plans, and test plans into structured PRD-style documents.

```text
使用 write-requirements-prd 把这些讨论记录整理成可测试、可追溯的 PRD、开发计划和测试计划。
```
