# Shared Contract Adapter

The canonical shared artifact contract is maintained by `write-prd` at `../../write-prd/references/shared-contracts.md`. Apply it without copying or overriding its status, RTM, baseline, change-impact, risk, or Grill phase-boundary rules.

For an active Grill review, use the canonical phase boundary: formal PRD content and metadata are frozen; the Grill V2 ledger is the per-answer authority; only `review-ended` with `ready-for-writeback`, valid `closureEvidence`, and a non-notes-only `writebackPolicy` can proceed to centralized writing.
