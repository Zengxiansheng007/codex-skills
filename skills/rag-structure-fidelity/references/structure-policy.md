# 结构策略

## 正文输入

- 正文唯一主输入为 `md`
- `doc/docx/pdf` 仅在可恢复结构时作为补充输入
- `.lakebook` / 语雀仅作目录对照和备用来源

## 结构单元

- 标题：用于目录层级和章节定位
- 语义块：作为最小判定单元
- 表格：按整表判定
- 列表：按整块判定，子项只做引用定位
- 图片：保留引用和位置，不把图片内文字自动升级为正式规则

## 阻断条件

- 扫描件 PDF
- 图片型 PDF
- 关键规则区块不可复原
- 文件整体结构失真
- 敏感内容未脱敏

## 目录对照

- 允许自动生成候选映射
- 候选映射只用于目录 / 检索 / 追溯辅助
- 不得作为正文块归并、版本合并、RC 生成或正式下游放行的唯一依据
