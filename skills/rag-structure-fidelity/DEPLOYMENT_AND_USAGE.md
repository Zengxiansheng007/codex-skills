# rag-structure-fidelity Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\rag-structure-fidelity`.
2. Keep structure rules, references, scripts, schemas, and fixtures together.
3. Confirm the target machine can access the intended source files and RAG workspace, normally `D:\RAG`.
4. Restart Codex or open a new task.

## Use
Use `rag-structure-fidelity` during document intake when Markdown structure, tables, image placeholders, Yuque outline mapping, or critical block recoverability must be preserved before RAG admission.

```text
使用 rag-structure-fidelity 检查这批 Markdown 是否结构可复原，关键规则区块不可复原则阻断。
```
