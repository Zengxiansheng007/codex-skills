# rag-schema Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\rag-schema`.
2. Keep schema references, fixtures, and validators together.
3. Restart Codex or open a new task.

## Use
Use `rag-schema` to validate local RAG frontmatter, manifests, schema-lite packet contracts, fixtures, evidence JSON, and structural integrity.

```text
使用 rag-schema 校验 D:\RAG 的 manifest、frontmatter 和 evidence JSON 是否符合契约。
```
