# rag-query Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\rag-query`.
2. Preserve query rules, evidence packet references, and schemas.
3. Confirm the target RAG workspace path, normally `D:\RAG`.
4. Restart Codex or open a new task.

## Use
Use `rag-query` to search the local RAG knowledge base for source-grounded evidence, RC status, candidate claims, conflict records, or read-only evidence packets.

```text
使用 rag-query 检索知识库，回答这个问题并列出证据来源和治理状态。
```
