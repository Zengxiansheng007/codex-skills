# rag-change-impact Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\rag-change-impact`.
2. Confirm the target machine has the same local RAG root, normally `D:\RAG`, or adapt prompts/configuration accordingly.
3. Restart Codex or open a new task.

## Use
Use `rag-change-impact` when a RAG source file changes and Codex must identify impacted RC records, tests, downstream packets, or generated assets.

```text
使用 rag-change-impact 分析这个 PRD 更新会影响哪些 RC、测试用例和下游交付物。
```
