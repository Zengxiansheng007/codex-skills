# grill-with-docs Deployment And Usage

## Deploy
1. Copy this folder to `%USERPROFILE%\.codex\skills\grill-with-docs`.
2. Preserve bundled document templates and references.
3. Restart Codex or open a new task.

## Use
Use `grill-with-docs` when a grill review should also create or update docs such as ADRs, glossary entries, or decision records.

```text
使用 grill-with-docs 追问这个方案，并同步沉淀 ADR 和术语表。
```
