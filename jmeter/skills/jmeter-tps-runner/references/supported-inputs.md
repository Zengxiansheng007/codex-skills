# 首期支持与限制

- Python3.11标准库，Windows现有Java和JMeter5.6.3；不自动下载、安装或更改全局properties。
- 标准ThreadGroup，intProp/stringProp整数字面并发；时长只读，longProp/stringProp可解析。保留请求、配置、注释和处理指令。DTD/实体声明不支持。
- scheduler关闭时，duration字段不代表实际定时时长；返回未知时长并要求确认循环/终止设置，不擅自开启scheduler。表达式scheduler未资格验证。
- 普通HTTP Sampler与明确可验证的执行上下文。前置须位于同一上下文且在目标之前；已确认前置和目标以外的HTTP全部禁用。只有当前目标评分。动态/空/Total名称、启用集合中同名标签不支持。
- 静态依赖检查是线索，不证明所有业务依赖完整。提取器和变量需人工复核。活动的脚本、插件或未资格验证的控制器/采样节点阻塞；不能改变祖先enabled来迁就隔离。
- 相对文件依赖移动布局未验证时阻塞。当前控制器在输出目录生成副本，带相对依赖的输入需后续布局适配或用户自行准备正确输入，不能由AI改JMX路径。
- Windows批处理已测试中文、空格、`&`和括号路径；含引号、百分号、感叹号、换行的参数明确拒绝，避免cmd展开。不承诺任意路径支持。
- 现有输出拒绝覆盖；未知在途不自动恢复。进程实际结束后才读取report及启动下一轮，等待不使用配置时长作为完成证据。
- 报告核验目前比较同标签样本/错误计数及官方字段一致性，不能识别所有数据错误。核验提示不改变评分。六轮有限搜索不保证全局最高TPS。
